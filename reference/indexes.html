Reference · Phase 2 (indexes)

Indexes & query planning

The short version of Lesson 0008. Sources: DDIA pp. 85–89, Use The Index, Luke, PostgreSQL docs.

Primary vs secondary

Primary key: unique, identifies the row. Secondary index (CREATE INDEX): keys can repeat; entries point to the row.

DDIA pp. 85–86

Heap vs clustered

Heap (PostgreSQL): rows unordered in a heap file, every index points into it. Clustered (InnoDB PK): rows live in the PK B-tree; secondary indexes store the PK → second lookup.

DDIA p. 86

Three steps of a lookup

1. tree walk (bounded, 3–4 pages) 2. walk matching leaves 3. fetch each row from the table. Steps 2–3 grow with matches → indexes shine when they narrow to few rows.

Winand, “Slow Indexes”

Composite index

Sorted by col 1, then col 2 within it (phone book). Leftmost prefix: (a,b,c) serves a, a+b, a+b+c, not b alone.

DDIA p. 87 · Winand

Column order

Equality first, range last. user_id = ? AND ts BETWEEN … → index (user_id, ts). Range first narrows only by the range. Same index also serves ORDER BY ts.

Winand, “Greater, Less and Between”

Covering index

Index holds every column the query needs → no table fetch (Index Only Scan). PostgreSQL: CREATE INDEX … (k) INCLUDE (v). Costs size and write speed; best on rarely changing tables.

DDIA p. 86 · PG docs

Query planner

Cost-based: estimates rows from statistics, picks the cheapest plan. Many matches → Seq Scan; some → Bitmap scan; one → Index Scan. Stats refreshed by (auto) ANALYZE.

PG “Using EXPLAIN”

EXPLAIN ANALYZE

Runs the query (side effects happen!). Check estimated vs actual rows first. Cost units are arbitrary, not ms. Buffers: shared hit = pages from memory.

PG docs

Index killers

Function on the column (UPPER(name)) → use an expression index. LIKE '%x' leading wildcard. Stale stats after bulk loads. Correlated columns underestimated.

Winand · PG docs

Buffer pool

Pages (8 KB PG, 16 KB InnoDB) cached in RAM. PG shared_buffers ≈ 25% RAM to start; OS page cache holds more. Time queries warm and cold separately.

PG docs · DDIA p. 89

Other index types

Multi-dimensional / R-tree (geo, Phase 11) · full-text inverted index (Lucene, Phase 11) · vector indexes (RAG, Phase 13).
