Reference · Phase 2 (sharding)

Sharding

The short version of Lesson 0016. Lesson 0017 will add consistent hashing. Sources: DDIA Ch. 6, Xu Ch. 1.

Sharding = partitioning

Each record in exactly one partition (shard / region / tablet / vnode), partitions on different nodes, each replicated. Scales data and load. Shard last: scale up and partition vertically (by feature) first.

DDIA pp. 199–201 · Xu p. 28

Skew & hot spots

Goal: even data and load. Skew → one hot partition, idle rest. Random placement is even but unfindable.

DDIA p. 201

Key range

Sorted ranges (encyclopedia). Cheap range scans. Time-ordered keys → all writes on newest partition. Prefix with e.g. sensor ID. Bigtable, HBase.

DDIA pp. 202–203

Hash of key

Partitions own hash ranges. Even spread, range queries hit all partitions. Stable hash (MD5), not language hashCode().

DDIA pp. 203–204

Compound key

Cassandra: hash first column for partition, sort by the rest. (user_id, ts): users spread, one user's time range = one scan.

DDIA pp. 204–205

Hot keys (celebrity)

Hashing can't split one key. Append random 2-digit suffix → 100 keys; reads fan out; track split keys. Or dedicated shards.

DDIA p. 205 · Xu p. 30

Secondary indexes

Local (by document): 1-shard writes, scatter/gather reads (tail latency) — MongoDB, Cassandra, ES. Global (by term): 1-shard reads, multi-shard async writes — DynamoDB GSI.

DDIA pp. 206–209

Rebalancing

Never hash % N (moves ~N/(N+1) of keys). Fixed many partitions per cluster (Riak, ES) · dynamic split/merge (HBase 10 GB, pre-split) · fixed partitions per node (Cassandra 256). Prefer human-approved moves.

DDIA pp. 209–214

Request routing

Any node forwards · routing tier · partition-aware client. Learn assignments via coordination service (ZooKeeper; MongoDB config servers + mongos) or gossip (Cassandra, Riak).

DDIA pp. 214–216

Costs

Cross-shard joins → denormalize (Xu). Cross-shard transactions → 2PC (Phase 5), slow. Global indexes lag. Rule: shard by what most queries/transactions filter on; check hot keys and time-ordered writes.

Xu p. 30 · DDIA p. 216
