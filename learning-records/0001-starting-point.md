# Starting point: no formal system design, real production ML experience

The user is an ML Engineer with ~14 months of production experience, has never studied system design formally, and knows its concepts "from hearsay". Networking, OS and DB fundamentals (Phase 0) are self-rated basic-to-medium and skipped. The user has seen DBs, APIs, queues and model serving in practice but lacks a unified mental model connecting them, so lessons should connect concepts to ML-serving situations they will recognise.

**Implications:** Start at Phase 1 vocabulary. Don't re-teach what TCP/HTTP/processes/indexes are, but hover-explain any term above that level.
